# Obsidian: одна папка — одна заметка

## Поведение

- «Настройки → Obsidian → Экспортировать все папки» отдаёт ZIP: один Markdown на папку, записи по времени, фото внутри текста.
- «Экспортировать аудио: выкл/вкл» в общих настройках задаёт значение по умолчанию (выкл). Меню папки позволяет переопределить его или вернуться к общему значению. Текст и фото включены всегда; видео и прочие файлы в этом режиме не прикладываются.
- Те же настройки и документы использует автоматическое получение через плагин. Подключение по коду и ограничение одной папкой сохраняются.
- HTTP v2 и ZIP v2 содержат документы папок. HTTP v1 остаётся для установленного плагина 0.1.0. Новый плагин понимает старые ZIP; прежние отдельные заметки не удаляет.
- Стабильный ID папки предотвращает дубли при обновлении/переименовании. Отдельный раздел для личных дополнений сохраняется при обновлении; правки внутри выгруженной истории вызывают сохранение новой версии отдельно.
- Неготовая папка откладывается целиком, чтобы не публиковать неполную историю. Пустая папка получает пустую заметку. Данные другого владельца недоступны, лимиты и проверки SHA сохраняются.
