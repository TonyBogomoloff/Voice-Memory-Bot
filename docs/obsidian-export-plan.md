# Obsidian: односторонний экспорт и мобильный плагин

Дата: 2026-10-26. База production и origin/main: `9185ca74cad844b62d712c428c333da616753e38`.

## Результат

Заметки Voice Memory можно выгрузить в ZIP для Obsidian и автоматически получить через плагин на Android, iOS и компьютере. Направление только **бот → Obsidian**. Обратный импорт в бот, синхронизация пользовательских правок и удалений, Notion — вне этой версии.

Пользователь подключает плагин одноразовым кодом из Telegram, выбирает папку в vault и получает заметки при открытии Obsidian, вручную или периодически, пока приложение работает. Подписка Obsidian Sync не нужна. Фоновая работа закрытого мобильного приложения не обещается.

## Формат и поведение

- Один редактируемый `.md` на заметку; исходная расшифровка и исходные медиа сохраняются.
- `voice_memory_id`, версия формата, дата, проект и тип записи в YAML. Не выдавать токены, Telegram file IDs или приватную конфигурацию.
- Имена включают стабильные ID. Вложения сохраняются без перекодирования, ссылки относительные. ZIP не содержит настроек `.obsidian`.
- Одинаковая модель документа для ZIP и API; SQLite остаётся источником данных бота, служебные `data/notes` не становятся пользовательским vault.
- Изменившаяся серверная заметка обновляется только если локальный файл совпадает с последним скачанным. Иначе новая серверная версия сохраняется отдельно, локальные правки не затрагиваются. Удаления на сервере не удаляют файлы в vault.
- Повторная доставка идемпотентна; состояние отмечается только после успешной записи. Идентификация не опирается только на имя файла или время изменения.
- API слушает loopback; публичный доступ только через подтверждённый HTTPS-маршрут. Пользователь подтвердил домен `audio-notes.korobkoff.com`; отдельный API не возвращает старый Mini App.
- Одноразовый код связывает плагин с владельцем Telegram; токен разрешает только чтение выбранного экспорта, хранится в виде хеша на сервере и может быть отозван.
- API и ZIP проверяют размер, состав, контрольные суммы, допустимые относительные пути и принадлежность файлов. Плагин не выполняет содержимое заметок и не обращается по внешним ссылкам из них.

## Проверка и выпуск

После каждого крупного этапа — целевые тесты и lint, отдельный коммит и push в `origin` без force. Финальное обновление `main` только fast-forward после интеграции. Публикация в каталоге сторонних плагинов Obsidian требует отдельной процедуры рассмотрения; готовый пакет и инструкция установки доступны независимо от неё. Проверка браузерным стендом/эмуляцией не называется проверкой на физических Android/iPhone.
