Voice Memory 0.2.0: одна папка Telegram-бота — одна заметка Obsidian, записи идут по времени.

В боте: **Настройки → Obsidian → Экспортировать все папки**. Текст и фото включены всегда, аудио включено по умолчанию. Переключатель **Экспортировать аудио** есть в общих настройках и в меню каждой папки; для папки можно вернуться к общему значению.

Автоматическое получение обновляет ту же заметку. Пиши свой текст в разделе **Мои дополнения** — он сохраняется при обновлении. При правках внутри выгруженной истории создаётся отдельная серверная копия. Прежние отдельные заметки версии 0.1, скачанные вложения и личные файлы автоматически не удаляются. Старые ZIP продолжают поддерживаться; отличающиеся ZIP-снимки сохраняются отдельными копиями.

**Обнови Voice Memory через BRAT**, затем нажми **Получить заметки**. Повторное подключение не требуется. [Установка и использование](https://github.com/TonyBogomoloff/Voice-Memory-Bot/blob/main/plugins/obsidian/README.md). Нужен Obsidian 1.11.4+; загрузка на Android/iPhone идёт, пока приложение открыто.

Проверены настоящий Python HTTP API/ZIP → TypeScript → тестовое хранилище: группировка, фото/аудио, порядок, повторы, переименования, сохранение личного текста и конфликты. Физические Android/iPhone отдельно не проверялись.
