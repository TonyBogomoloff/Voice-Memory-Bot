# Voice Memory для Obsidian

Плагин собирает каждую папку Telegram-бота Voice Memory в одну Markdown-заметку: записи по времени, текст, фото и исходное аудио. Работает с API Obsidian для Android, iPhone/iPad и компьютера; требуется Obsidian **1.11.4 или новее**. Обратной отправки в бота нет.

## Установка на Android и iPhone

1. В Obsidian открой **Settings → Community plugins**, разреши сторонние плагины, найди **BRAT**, установи и включи его. Нужен BRAT 1.1.0 или новее.
2. В настройках BRAT нажми **Add beta plugin**, укажи `TonyBogomoloff/Voice-Memory-Bot`, выбери последнюю версию и включение плагина после установки.
3. В Telegram открой **Настройки → Obsidian → Подключить устройство**. Для одной папки открой её меню **Для Obsidian**. Скопируй одноразовый код; он действует 10 минут.
4. В Obsidian открой **Settings → Voice Memory**, введи код, нажми **Подключить**, затем **Получить заметки**. Сервер уже указан: `https://audio-notes.korobkoff.com`.

Отдельный код нужен для каждого устройства. Ключ сохраняется в локальном SecretStorage Obsidian и не попадает в `data.json`. Не нужен GitHub-токен или платная подписка Obsidian Sync. В общий каталог Obsidian этот плагин пока не опубликован; BRAT устанавливает его из GitHub Release.

Пока Obsidian открыт, плагин проверяет заметки при открытии и раз в минуту. На закрытом или приостановленном мобильном приложении загрузка ждёт следующего открытия. Полученные файлы доступны офлайн.

## Компьютер и ручная установка

Можно использовать BRAT по той же инструкции. Другой вариант: скачай [пакет плагина](https://audio-notes.korobkoff.com/plugin/voice-memory.zip), распакуй папку `voice-memory` в `<vault>/.obsidian/plugins/`, перезапусти Obsidian и включи **Voice Memory**. Для нестандартного каталога настроек используй его вместо `.obsidian`. Ручная установка на iOS через скрытые папки неудобна, поэтому для телефонов рекомендуется BRAT.

## Экспорт папок и аудио

В Telegram открой **Настройки → Obsidian**. Кнопка **Экспортировать все папки** скачивает ZIP со всеми папками. Для одной папки открой её меню **Для Obsidian → Экспортировать папку**. Подключённый плагин получает те же папки автоматически; ZIP для этого не нужен.

**Экспортировать аудио: вкл** — значение по умолчанию. Нажми переключатель, чтобы оставить только текст и фото. В меню конкретной папки можно задать отдельное значение; кнопка **Как в общих настройках** отменяет её переопределение. Настройка действует и для ZIP, и для автоматического получения. Видео и прочие документы в этом режиме не прикладываются.

Фото и аудио сохраняются файлами в `attachments`, рядом с каждой записью появляется встроенное вложение. Аудио выгружается в исходном формате. [Поддержка кодеков зависит от устройства](https://help.obsidian.md/file-formats); физические Android/iPhone отдельно не проверялись. Отключение аудио убирает его из новой версии истории, уже скачанные файлы остаются в vault.

## Перенос ZIP без подключения

В боте выбери **Obsidian → Экспортировать все папки** и сохрани все части экспорта на устройство. В настройках плагина нажми **Загрузить ZIP** и выбери все части вместе. Сначала проверяются пути, размеры и контрольные суммы; заметки без нужной части вложения откладываются. Для больших архивов используй экспорт отдельных папок. Одна загрузка ограничена 200 МБ в сумме, один файл — 64 МБ. Markdown можно распаковать в vault и без плагина; относительные ссылки на вложения сохранятся.

## Правки, повторная загрузка и отключение

- Папка назначения по умолчанию — `Voice Memory`. Внутри находятся Markdown-файлы папок и `attachments` с оригиналами.
- У заметки есть стабильный `voice_memory_id` папки в YAML. Повторное получение не создаёт дубликатов. Переименование внутри папки экспорта поддерживается; ID сохраняй.
- Пиши свой текст в конце, в разделе **Мои дополнения**: автоматическое получение обновляет историю выше, сохраняя этот раздел. Если изменить саму историю из бота или её служебную границу, новая версия сохраняется рядом в файле `… (Voice Memory …).md`; твой файл и изменённые вложения сохраняются.
- ZIP считается отдельным снимком: если версия отличается от уже имеющейся, создаётся отдельная копия без замены.
- Состав истории следует папке в боте: перенос записи обновляет истории исходной и новой папок. Удаление в боте не удаляет сами файлы в Obsidian. Удалённый только в Obsidian файл может загрузиться снова. Перенос за пределы папки экспорта выводит файл из области плагина.
- **Отключить устройство** удаляет локальный ключ. Для отзыва доступа на сервере открой список устройств в Telegram → Настройки → Obsidian и отключи нужное устройство.

## Обновление с 0.1

Обнови Voice Memory через BRAT до **0.2.0** и нажми **Получить заметки**. Существующее подключение сохраняется. Появятся заметки целых папок; старые отдельные заметки 0.1 остаются на месте, чтобы сохранить твои правки. После проверки новых историй их можно убрать вручную. Плагин продолжает читать старые ZIP.

## Разработка и проверка

Из корня Python-проекта установи `.[dev]` в `.venv`. В этой папке выполни `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm test`, `pnpm build` (Node.js 24). Исходники не используют Node/Electron API во время работы плагина. Сборка лежит в `dist/`; эти четыре файла входят в серверный релиз и раздаются через HTTPS. `build.mjs test` создаёт только синтетические заметки и проверяет настоящий Python ZIP и HTTP API через TypeScript-клиент и импортёр. Перед коммитом выполни `python scripts/check_obsidian_package.py` из корня. Собранные assets коммитятся вместе с исходниками; публикация по tag, совпадающему с `manifest.json`, выполняется workflow `obsidian-release.yml`.

Объявленная совместимость с мобильным API и автоматические проверки не заменяют ручную проверку на физических Android/iPhone.
