# Voice Memory Bot — 30 секунд

Вертикальный ролик на русском: 720 × 1280, 30 кадров/с, ровно 900 кадров.
Всё понятно без звука. Готовый MP4, обложка, раскадровка и проверка находятся
в `../../output/remotion/`. Подключение ролика к `/start` в эту задачу не входит.

## Сценарий

| Время | Сцена |
| --- | --- |
| 0–3 с | «Хорошие мысли не теряются», синий диктофон с актуальной аватарки |
| 3–9 с | В чате уже есть фото маяка; голосовая идея о поездке становится текстом |
| 9–14 с | Переключение «Идеи» → «Поездка» возвращает сохранённые фото и запись |
| 14–21 с | Ответ на запись «Собери план поездки» вызывает ИИ |
| 21–27 с | Экспорт истории и оригиналов в ZIP |
| 27–30 с | «Начни с одной мысли» |

Вымышленные сообщения написаны для ролика. Личный аккаунт и реальные
переписки не использовались. Время ожидания обработки сокращено для монтажа,
оно не является замером скорости бота. Ответ ИИ — иллюстративный пример.

Функции и названия элементов сверены с production-коммитом
`1bf515f00698dcb99b9b9d226c71ec36e35c16ba`:

- `folder_menu.py`: собственные папки, отметка активной папки, поле ввода;
- `bot.py`: расшифровка, экспорт PDF/Markdown и оригиналов;
- `ai_bot.py`: инструкция ответом на запись и сохранение ответа;
- `zip_parts.py`: имя ZIP `voice-memory-all-001.zip`.

## Стиль и материалы

Основа — ролик Your Secret Agent v4 и обсуждение в чате
«Спланировать видео-презентацию бота». Используется тот же Remotion 4.0.538,
тёмный фон, Telegram Android, плавные появления, подписи вне телефона.
Экран 360 × 800 (9:20) не растягивается. Текст сообщений остаётся обычным
белым; цвет используется в пояснениях и настоящих элементах интерфейса.

Версия 2 использует `public/bot-avatar-v2.jpg` — актуальную аватарку
`@your_audio_notes_bot`, повторно скачанную через Telegram Bot API 26.10.2026.
Источник, идентификатор и SHA-256 сохранены в `bot-avatar-v2.source.json`.
`public/blue-recorder-cutout-v2.png` — её прозрачная версия для заставок.
`public/trip-lighthouse-v2.png` — сгенерированное фото для вымышленной поездки;
оно видно в чате во время расшифровки и после переключения папки.
Оба новых изображения созданы встроенным imagegen, запросы сохранены рядом
в `.prompt.txt`. Исходная аватарка не изменена. Материалы v1 сохранены.
Шрифты IBM Plex Sans и Roboto локальны, лицензии включены.
Во время рендера внешние медиа и аккаунты не нужны.

## Сборка

Нужны Node.js, pnpm и Chrome. Зависимости закреплены lock-файлом.

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm render --browser-executable=/usr/bin/google-chrome
pnpm poster --browser-executable=/usr/bin/google-chrome
python3 validate_video.py out/voice-memory-bot-v2-ru.mp4 out/validation-v2.json
```

Источники: [Remotion render](https://www.remotion.dev/docs/cli/render),
[Composition](https://www.remotion.dev/docs/composition).
Тайминг задан в `src/timing.ts`, тексты — в `src/demo-copy.json`.
Вся анимация зависит от номера кадра; случайных и сетевых эффектов нет.

После рендера проверь ключевые кадры, полное декодирование FFmpeg, длительность,
размер кадра, количество кадров и SHA-256. Готовый файл предназначен для Telegram:
H.264, yuv420p, BT.709, faststart. `node_modules/` и `out/` не входят в Git.

## Видеоподсказки Help

`src/help-index.tsx` регистрирует восемь самостоятельных композиций по 10 секунд
(300 кадров). В `src/help-video.tsx` — сценарии, подписи и тайминг:

| Кнопка | Пример |
| --- | --- |
| Сохранить запись | Папка → голосовая → расшифровка |
| Папки и порядок | «＋» → название → запись в новой папке |
| Работа с ИИ | Ответ `/ai` → задача → список дел |
| Картинки с ИИ | Фото → ответ `/ai` → вопрос о снимке |
| Найти запись | `/search маяк` → результат → исходная запись |
| Перенос и удаление | Ответ `/move` → папка назначения → подтверждение переноса |
| Скачать архив | `/export` → PDF + оригиналы → ZIP |
| Настроить бота | Настройки → включить кнопки → действия у новой записи |

```bash
pnpm check
pnpm render:help
# Только изменённая тема:
pnpm render:help --topics settings
```

Результаты и квитанции полной проверки: `../../output/remotion/help/`.
Системный Chrome используется с `chrome-for-testing`, чтобы не зависать
на устаревшем headless-режиме. Формат тот же: 720 × 1280, H.264, yuv420p,
BT.709, faststart, без звука. После рендера визуально проверь промежуточные
экраны и финальные результаты. Примеры вымышлены; ожидание обработки сокращено.

Каждый пункт Help отправляет соответствующий MP4 через `sendVideo` с прежним
пояснением над видео и всеми восемью кнопками внизу. Следующая тема заменяет
предыдущее сообщение только после успешной отправки. `/help` открывает обычный
текстовый список тем. При недоступности локального файла остаётся текстовая
подсказка. Эти клипы не подключены к `/start`.
