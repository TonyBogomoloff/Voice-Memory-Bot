# Voice Memory Bot — 30 секунд

Вертикальный ролик на русском: 720 × 1280, 30 кадров/с, ровно 900 кадров.
Всё понятно без звука. Готовый MP4, обложка, раскадровка и проверка находятся
в `../../output/remotion/`. Подключение ролика к `/start` в эту задачу не входит.

## Сценарий

| Время | Сцена |
| --- | --- |
| 0–3 с | «Хорошие мысли не теряются», диктофон с аватарки |
| 3–9 с | Голосовая идея о поездке становится текстом; оригинал остаётся |
| 9–14 с | Переключение «Идеи» → «Поездка» возвращает сохранённую запись |
| 14–21 с | Ответ на запись «Собери план поездки» вызывает ИИ |
| 21–27 с | Экспорт истории и оригиналов в ZIP |
| 27–30 с | «Начни с одной мысли» |

Вымышленные сообщения написаны для ролика. Личный аккаунт и реальные
переписки не использовались. Время ожидания обработки сокращено для монтажа,
оно не является замером скорости бота. Ответ ИИ — иллюстративный пример.

Функции и названия элементов сверены с production-коммитом
`6ca7a1e512d91e0a63f426c9a84d86c4b129c3e9`:

- `folder_menu.py`: собственные папки, отметка активной папки, поле ввода;
- `bot.py`: расшифровка, экспорт PDF/Markdown и оригиналов;
- `ai_bot.py`: инструкция ответом на запись и сохранение ответа;
- `zip_parts.py`: имя ZIP `voice-memory-all-001.zip`.

## Стиль и материалы

Основа — ролик Your Secret Agent v4 и обсуждение в чате
«Спланировать видео-презентацию бота». Используется тот же Remotion 4.0.538,
тёмный фон, Telegram Android, плавные появления, подписи вне телефона.
Экран 360 × 800 (9:20) не растягивается. Текст сообщений остаётся обычным
белым; цвет используется в пояснениях и настоящих элементах интерфейса.

`public/bot-avatar.png` — существующая аватарка проекта.
`public/recorder-cutout-v1.png` — её прозрачная версия, созданная встроенным
imagegen. Точный запрос сохранён рядом в `.prompt.txt`; исходная аватарка
не изменена. Шрифты IBM Plex Sans и Roboto локальны, лицензии включены.
Во время рендера внешние медиа и аккаунты не нужны.

## Сборка

Нужны Node.js, pnpm и Chrome. Зависимости закреплены lock-файлом.

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm render --browser-executable=/usr/bin/google-chrome
pnpm poster --browser-executable=/usr/bin/google-chrome
python3 validate_video.py out/voice-memory-bot-v1-ru.mp4 out/validation-v1.json
```

Источники: [Remotion render](https://www.remotion.dev/docs/cli/render),
[Composition](https://www.remotion.dev/docs/composition).
Тайминг задан в `src/timing.ts`, тексты — в `src/demo-copy.json`.
Вся анимация зависит от номера кадра; случайных и сетевых эффектов нет.

После рендера проверь ключевые кадры, полное декодирование FFmpeg, длительность,
размер кадра, количество кадров и SHA-256. Готовый файл предназначен для Telegram:
H.264, yuv420p, BT.709, faststart. `node_modules/` и `out/` не входят в Git.
