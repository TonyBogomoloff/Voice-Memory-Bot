# Voice Memory Bot: правила проекта

Эти правила действуют для всех агентов и чатов проекта, включая отдельные worktree.
Актуальная общая копия: `/home/tony/Documents/ChatGPT/voice_memory_bot/AGENTS.md`;
перед работой в старом worktree сверяйся с ней.

## Завершение задачи и автодеплой

- Любую задачу с изменениями в проекте доводи до проверенного развёртывания на сервере.
  Деплой и необходимый перезапуск этого бота заранее разрешены пользователем;
  не заканчивай на «готово локально» и не спрашивай повторное разрешение на выкладку.
- Исключения: пользователь прямо просит только анализ, запрещает изменения/деплой
  либо задаёт вопрос, не требующий изменений. Такие указания имеют приоритет.
- Перед выкладкой зафиксируй только относящиеся к задаче изменения и выполни целевые проверки.
  Полный набор тестов запускай при существенных изменениях, интеграции или выявленных сбоях.
- Сервер: SSH host `my-server`, пользователь `tony`.
  Приложение: `/home/tony/Desktop/_code/voice_memory_bot`.
  Служба пользователя: `voice-memory-bot.service` (`systemctl --user`).
- Источник текущей production-версии — серверный `release.json` с полным SHA и хешами файлов.
  Собирай релиз поверх этой версии, сохраняя результаты параллельных задач.
  Не выкладывай старую ветку целиком и не включай чужие незавершённые изменения.
- Сериализуй выкладки через `<app>/.deploy.lock`; перед заменой повторно сверь SHA и хеши.
  При несовпадении обнови базу, объедини изменения и повтори необходимые проверки.
- Сначала проверь кандидата, сохрани резервную копию исходников, квитанции и SQLite.
  Дождись завершения выполняющейся обработки, затем обнови файлы и перезапусти только эту службу.
  Не перезаписывай `config.json`, `data/`, ключи и авторизацию; сохрани возможность отката кода.
- После деплоя проверь `active/running`, соответствие файлов новому `release.json`,
  отсутствие новых ошибок и сохранность очереди/архива. Одного статуса процесса недостаточно.
- В финале кратко сообщи установленный SHA и результат проверок. Если деплой заблокирован,
  укажи конкретную причину и оставшийся шаг; не представляй локальный результат как выложенный.
